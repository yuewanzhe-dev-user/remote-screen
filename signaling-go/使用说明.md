# 智慧投屏 · 阶段1 使用说明（WebRTC）

教室一键投屏：**黑板一个 exe + pad 一个 apk**，无需 Node、无需 ffmpeg，师生不用填 IP/房间号。

## 给老师（智慧黑板 Win10）

1. 拿到 `智慧投屏-黑板.exe`
2. 双击运行  
   - 可选：`智慧投屏-黑板.exe 8080 "三年二班"`（端口 + 显示名）
3. 程序会：
   - 启动信令与接收页
   - 在局域网广播，让 pad 发现
   - 自动打开浏览器等待投屏
4. 学生/老师在 pad 上点本班黑板名称即可出画
5. 关掉 exe 窗口即停止服务

> 若浏览器没自动弹出，手动打开：`http://127.0.0.1:8080/`

## 给学生 / 老师 pad

1. 安装 `智慧投屏` apk
2. 连接**教室同一 WiFi**（须能与黑板互通，不能开客户端隔离）
3. 打开 App → 自动出现黑板列表 → **点击**对应名称
4. 系统弹出「录制/投射」授权 → 允许
5. 黑板浏览器应显示 pad 画面；状态为「投屏中」
6. 停止：点 App「停止投屏」

搜不到黑板时：展开「高级设置」，手输 `黑板IP:8080`，房间一般填 `default`。

## 多人抢投

后一个 pad 点投屏会**顶掉**前一个；前一个 pad 提示「已被其他设备投屏替换」。

## 本机验证（开发）

```bash
# 黑板端
cd signaling-go
go mod tidy
go run . 8080 "测试黑板"

# pad：装 webrtc-android 编译出的 apk，与电脑同一局域网
```

日志：exe 同目录 `智慧投屏.log`。
