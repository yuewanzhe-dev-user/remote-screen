# 智慧投屏 · 阶段1 使用说明（WebRTC）

教室一键投屏：**黑板一个 exe + pad 一个 apk**，无需 Node、无需 ffmpeg，师生不用填 IP/房间号。

## 给老师（智慧黑板 Win10）

1. 拿到 `智慧投屏-黑板.exe`
2. 双击运行  
   - 可选：`智慧投屏-黑板.exe 8080 "三年二班"`（端口 + 显示名）  
   - 可选 token：`智慧投屏-黑板.exe 8080 "三年二班" "班级密钥"`（**默认不设**，不影响一键连接）
3. 程序会：
   - 启动信令与接收页
   - 在局域网广播，让 pad 发现
   - **优先 WebView2 单窗口**；失败则 Edge 应用模式 / 系统浏览器
4. 学生/老师在 pad 上点本班黑板名称即可出画
5. 顶部栏 **「断开投屏」** 可踢掉当前 pad
6. 关掉窗口即停止服务

> 若没弹出窗口，手动打开：`http://127.0.0.1:8080/`  
> WebView2 需系统已装 Edge WebView2 Runtime（Win10/11 一般自带）

## 给学生 / 老师 pad

1. 安装 `智慧投屏` apk
2. 连接**教室同一 WiFi**（须能与黑板互通，不能开客户端隔离）
3. 打开 App → 自动出现黑板列表 → **点击**对应名称
4. 系统弹出「录制/投射」授权 → 允许
5. 黑板浏览器应显示 pad 画面；状态为「投屏中」
6. 停止：点 App「停止投屏」

搜不到黑板时：展开「高级设置」，手输 `黑板IP:8080`，房间一般填 `default`。

## 多人抢投

后一个 pad 点投屏会**顶掉**前一个；前一个 pad 提示「已被其他设备投屏替换」。

## 阶段2 全量（稳定性 + 画质）

| 项 | 说明 |
|---|---|
| Service 防叠 | 重复启动先 stop 旧 RtcClient |
| 信令心跳 | pad 10s ping / 信令 pong |
| ICE 队列 | answer 未到先缓存 |
| 断线退避 | 2s×n 上限 15s；kicked 禁止重连 |
| 顶替 | kicked + session-reset，旧 pad 立刻停轨 |
| 发送 stats | logcat `codec/fps/kbps/rtt/loss` |
| 接收 stats | 状态栏 `分辨率 · H264 · fps · kbps` |
| 弱网降码率 | 丢包/RTT 高 → 降至最低 600kbps，恢复再升 |
| 关键帧 | 连通/协商后 + 每约 3s 请求；浏览器解码停滞时 PLI |
| 隔离提示 | 8s 搜不到黑板 → 同 WiFi / 客户端隔离 / 手输 IP |

### 顶替验收

1. pad A 投屏中  
2. pad B 点同一块黑板投屏  
3. A 应显示「已被其他设备投屏替换」且**不再自动连回**  
4. 黑板应在 1～2 秒内只显示 B 的画面（不花屏、不回闪 A）

### 画质/网络验收

1. 正常投屏状态栏约 `H264 · 15~20fps · 1~2.5Mbps`  
2. pad logcat 有 `📊 send codec=H264` 与码率上下调日志  
3. 故意弱网（限速/干扰）应出现 `↓ 弱网降码率`，恢复后 `↑ 网络恢复升码率`  
4. 关掉黑板 exe 时 pad 搜列表 8 秒后出现隔离/同网提示

## 阶段3

| 项 | 说明 |
|---|---|
| WebView2 单窗口 | Windows 内嵌显示;失败回退 Edge/浏览器 |
| 历史黑板置顶 | pad 列表 `★` 标记本机投过的,并排前面 |
| 串班名展示 | 列表大字显示教室名 + IP |
| 教师断开 | 页面「断开投屏」/ `POST /api/stop` |
| 房间 token | **默认关闭**;启用后发现广播自动带 token,**一键仍可用** |
| 画质控制 | **仅黑板 exe 顶栏可切换**;学生 pad 不可改 |

### 画质三档（教师在 exe 上选）

| 档位 | 约分辨率 | 说明 |
|---|---|---|
| **均衡(默认)** | ~1600×900 | 清晰与延迟折中,推荐 |
| **清晰** | 1080p | 更清,延迟/带宽略高 |
| **流畅** | 720p | 更跟手,弱网更稳 |

切换后会通知正在投屏的 pad 调码率/帧率并补关键帧;分辨率大改建议学生重新点一次投屏更稳。

### Token 会不会影响自动连接？

**不会（默认）。**  
未配置 token 时与以前完全一样。  
只有老师启动时加了第 4 参数密钥，才会校验；此时密钥会写进 UDP 发现包，pad 点列表时自动带上，师生仍不用手填。
